## 職務要約

高校卒業後、データベース専門の企業にインフラエンジニアとして入社し、サーバ構築の技術を習得。
その後プログラミングに関心を持ち受託開発企業へ転職、複数の常駐プロジェクトで経験を積んだのち、大手メガベンチャー企業へ。
現在はフリーランスとして、都内のベンチャー企業を中心に開発を支援しています。

- 開発歴15年目、うちWebアプリケーションエンジニアとして10年以上の経験がある
- テスターからプロジェクトリーダーまで様々なポジションで働いた経験がある
- 要件定義から運用まで幅広く対応でき、プロジェクトリーダー / ITコンサルタント / システム運用の経験から、開発プロセス全体を見渡して動ける
- 現在、フルスタックエンジニアとしてWeb開発全般に取り組んでいる
    - 開発チームの立ち上げから運用まで
    - 継続的デリバリー
    - 最新技術の調査・導入
    - 技術選定・検証
    - UI/UXデザイン検討

    - リーダーシップ(10人程度の開発グループ)
